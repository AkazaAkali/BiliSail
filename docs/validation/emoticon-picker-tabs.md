# 评论与直播表情选择

日期：2026-10-05。在现有未提交工程上增量修改。

## 交互

视频评论表情入口由输入框下方展开改为居中弹窗；直播播放器及侧栏的表情入口使用同一弹窗样式。弹窗顶部按服务端表情包系列显示子标签，点击切换，系列较多时可横向滚动。内容区只构建当前系列，表情列表独立滚动。

评论选中表情后关闭弹窗，替换草稿选中文字或插入光标处，恢复输入焦点；取消保留草稿。直播普通表情追加草稿，图片表情沿用预览，未解锁表情保留锁定提示及禁用选择。选择表情不发送评论或弹幕，发布／发送仍由用户另行点击。

弹窗保留现有加载、空结果和失败重试状态，使用原页面 ProviderContainer；评论返回选择结果时检查页面身份、账号 scope 和 session epoch。共享组件只负责展示，不访问 Repository 或协议模型；两处仍使用各自控制器和领域表情类型。

## 验证

### 2026-10-22 评论输入区收起

视频、影视和动态复用的 `CommentsPanel` 默认只显示单行输入框，隐藏底部表情和发布按钮。输入区获得焦点后，以 200 毫秒的高度和透明度过渡展示操作区；编辑时最多显示四行。点击输入区之外后平滑收起，保留草稿和回复目标；键盘焦点移动到操作按钮时保持展开。系统要求减少动画时直接切换。

输入文字使用继承应用字体的 13 号字号、1.4 倍行高；输入框内边距为横向 10／纵向 6，外侧为横向 12／纵向 8。操作区间距缩为 4，表情图标为 18，表情和发布按钮最小高度为 32；大字号下仍按内容自然增高。默认字号的输入框高度不超过 36，整个收起输入区不超过 52（Flutter 逻辑像素）。

表情按钮和发布按钮属于同一输入点击区域，点击不会提前收起输入区；表情弹窗打开时保持输入区高度，选择或取消后恢复编辑焦点。原有单次发布、未知结果锁定和账号隔离规则继续保留。

定向离线测试 46 项通过，覆盖默认单行、展开中间帧、失焦收起、多行草稿保留、Tab 访问操作按钮、表情选择/取消、窄屏两倍字号、键盘上的四行发布，以及视频/影视评论详情返回和动态回复。日志：`artifacts/comment-composer-targeted.log`。未执行真实账号发送或设备界面验收；当前没有运行中的 Flutter 调试实例可供热重载。
