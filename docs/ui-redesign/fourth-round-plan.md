# 晴湾第四轮调整

日期：2026-10-25。按用户最新七项要求实施，保留第三轮已经落地的双/多标签、独立播放窗口与“我的”四内容标签。

## 导航与页面层级

- 第 1 项按“多标签模式左上角不显示返回按钮”理解；双标签保留返回入口。
- 首页、动态、直播、我的属于同一固定根页面。切换一级入口不新增工作区标签、不写入临时页面返回栈；首页内容与我的四标签分别保留控制器、滚动位置和筛选。
- 双标签浏览返回关闭离开的非固定临时页面，清理其缓存和返回记录；搜索、UP 主页等不再残留为隐藏页。页内详情/模态返回仍优先。媒体返回优先消费上一媒体记录，历史为空则关闭播放窗口并释放会话。

## 直播、消息和热门

- 桌面直播直接显示“推荐直播 / 我的关注 / 观看记录”，移除孤立的“直播”外层标签与“全部分区”入口，保留推荐列表中已有的分区筛选功能。头像和搜索在直播保留；Android 窄屏仍只有首页、动态、我的、设置四个一级入口，直播归首页。
- 消息分类复用首页的 PagingTabStrip、字号、选中颜色和动画指示线，保留未读数量、横向滚轮、私信会话及窄屏返回。消息、下载、设置使用协调的现有线性圆角图标，不增加字体/资源依赖。
- 热门包括综合热门、每周必看、入站必刷、排行榜；独立排行榜导航合入热门，旧排行榜链接兼容。每周必看支持官方期数及当期内容；入站必刷使用独立只读接口；排行榜继续使用已有动态分区目录和 WBI 请求，不混用普通分区 ID。
- 核对官网/API 与相邻参考项目的具体源码和提交，仅参考协议和行为；不复制第三方应用源码。新增端点登记鉴权、参数、分页、取消和错误边界，保留既有视频卡与懒加载网格。

- 已授权的三个 Sol 6.1 xhigh 代理分别处理工作区模型/组合根、共享外壳/直播导航、热门协议/页面；主代理负责消息样式、集成审查、全量检查和构建。
- 使用 fake repository/transport 的单元与 Widget 回归，覆盖新接口、期数切换和旧响应隔离、根页面状态保留、返回销毁、桌面与窄屏导航、消息横向滚动。
- 按用户最新范围，仅自动回归与构建 Windows Release；用户在本轮构建期间取消 Android 构建，因此本轮不产出 Android 新包。不开启 GUI/实机/native 集成测试，不操作现有预览窗口；macOS 构建留待对应主机，最终由用户手动验收。
