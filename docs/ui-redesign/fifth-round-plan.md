# 晴湾第五轮调整

日期：2026-10-25。依据用户最新五项反馈，在第四轮工作区与热门实现上继续调整。

## 改动方案

- 消息、下载、设置与首页、动态、直播、我的同层，统一选中固定根标签，不打开独立工作区标签。根容器按需保留频道、账号、消息、下载、设置五个有限分支；每个分支保留页面状态、滚动和必要 ProviderScope，隐藏分支停止分页与快捷键，账号变化仍清理私有状态。消息收件人、设置分类和旧 URI 继续支持。
- 设置页仅保留分类和设置内容，去掉通用头像、搜索及工具按钮。侧栏消息/下载选中时不再同时选中“我的”；窄屏底部仍为首页、动态、我的、设置。
- 按用户追加要求，同步优化首页、动态、直播、我的四个导航图标，统一线条、尺寸与选中状态；侧栏和窄屏底栏共用映射，正式应用图标保持。
- 热门四个子标签采用与首页/直播/消息相同的字重、按钮间距和短指示线，沿用共享 PagingTabStrip 的交互、横向滚动和分页进度；不改热门数据、切期缓存或视频卡内容。
- 窄屏共享网格列间距由 20 缩到 10 逻辑像素，页面左右留白由 20 缩到 12；原两列与大字体断点保留，桌面留白与卡片内容不变。推荐、热门、其他首页卡片和历史共用局部宽度自适应边距，搜索保留已有 12px 窄屏边距。
- 我的顶部恢复名称、等级、经验/满级文字、细进度、硬币、关注/粉丝/动态。使用现有 AccountOverview；宽屏紧凑横排，窄屏分行，保留头像主页、统计导航、登录/退出、资料失败重试与四个内容标签。不恢复之前删除的额外业务入口。

## 分工与验证

沿用已授权的三个 Sol 6.1 xhigh 子代理，分别负责根导航、外壳与热门标签、账号资料；主代理负责共享卡片布局、集成审查、文档和最终检查。保持现有未提交修改，不新增依赖或修改视频协议。

以单元/Widget 回归验证页面身份与状态保留、消息意图、设置分类、隐藏刷新隔离、宽窄屏与大字体。完成后执行 `tool/check.ps1 -SkipPub`，仅构建 Windows Release。按用户当前要求不做 Android/macOS 构建，不运行或操作客户端，不进行实机/native 集成和性能测试，由用户手动验收。
